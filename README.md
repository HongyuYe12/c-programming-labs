# C Programming Labs

Two introductory C programs focused on structures, arrays, branching, loops, formatted input/output, and aggregation.

## Programs

### GPA Calculator

`gpa-calculator.c` stores five course records in structures, converts numerical marks to letter grades and grade points, prints a summary table, and calculates a weighted GPA.

### Fruit Inventory Summary

`fruit-inventory.c` records fruit name, category, unit price, and mass, then calculates total mass and value and groups the records by category.

## Build

```bash
gcc -std=c11 -Wall -Wextra -pedantic gpa-calculator.c -o gpa-calculator
gcc -std=c11 -Wall -Wextra -pedantic fruit-inventory.c -o fruit-inventory
```

## Verification

Both programs were compiled successfully with GCC 16.1 before publication.
